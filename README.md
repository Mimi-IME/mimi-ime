Mimi (Meme hay MeoMeo hay Mimi tuỳ cách bạn gọi) là bộ gõ tiếng Việt được viết bằng Rust cho
Linux và môi trường Wayland!!! >;3

**⚠️ Lưu ý:** Đây là dự án nghiên cứu hơn là có thể sử dụng hằng ngày nên có thể bị thiếu nhiều tính năng
và có thể phát sinh nhiều lỗi. Hãy cân nhắc trước khi sử dụng.

## Hỗ trợ

Nếu bạn cần trợ giúp có thể tạo báo cáo lỗi hoặc vào phòng chat trực tuyến Matrix ở đây.

[Tham gia phòng Matrix](https://matrix.to/#/#mimi-ime:matrix.org)

## Đóng góp

Nếu bạn muốn đóng góp đừng ngần ngại tạo báo cáo lỗi hay gửi code trên PR cho mình.

Đọc tài liệu dự án ở [đây](./docs/project-overview.md) nếu bạn cần.
